# Casualties_Unknown_UnchippedToggles
Mod that adds toggles to the Unchipped mode, allowing you to remove a mechanic in Unchipped that you dislike. This mod has not been tested for the Steam demo release but I believe it should work (please notify me if it does not so I can update this)

NOTE: I am new to modding and haven't worked on this mod for a couple of months, as of right now the only feature this mod has is the removal of Unchipped's LOS (Line of Sight) mechanic that prevents vision past objects. Should I choose to continue development or get assistance then the mod will include toggles for all mechanics in Unchipped. Toggles are not yet implemented so removing the mod is required to bring back LOS and Solar Struck is also effected by this mod.
